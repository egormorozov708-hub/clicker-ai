Сквозные тесты проводились в режиме --dry-run на синтетическом полноэкранном окне ClickerTest (кадры игры), клики не выполнялись, только логировались.

1) Второй уровень, --upgrade-interval 3 --no-bonuses, 12 с:
   - модель стабильно находила game (1 рамка) и 4 кнопки improvement;
   - бот кликал по game и раз в 3 с покупал ровно одно улучшение, перебирая кнопки по очереди: «1/4», «2/4», «3/4»;
   - итог: 144 кадра, 73 действия (game 70, improvement 3), 12.0 с.

2) Рекламный попап поверх игры, --no-improvements --no-bonuses, 8 с:
   - модель находила крестик advertising с уверенностью 0.95, фильтр app.py пропустил рамку;
   - пока реклама видна, кликов по game не было;
   - закрытие рекламы повторялось с кулдауном 3 с (в статичном тесте попап не исчезал);
   - итог: 104 кадра, 3 действия (только advertising), game 0, 8.0 с.

Оба сценария подтверждают: улучшения покупаются по одному с возвратом к game, реклама имеет приоритет и блокирует клики по игре, общий примитив click_box() используется для всех действий.
